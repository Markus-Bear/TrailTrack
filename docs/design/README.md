# TrailTrack Design

UML diagrams and low-fidelity UI wireframes for TrailTrack, produced with
PlantUML (diagrams) and HTML (wireframes). Scope is the whole system, with
Iteration 1 covered in detail. PNG for reports, SVG for sharp scaling.

## Diagrams (`rendered/`)

| File | What it shows |
|---|---|
| `architecture` | System architecture: components and how they connect |
| `use-case` | Use case diagram, whole system, colour-coded by iteration |
| `domain-model` | Domain model class diagram, whole system, colour-coded by iteration |
| `ui-flow` | Screen navigation, whole system |
| `seq-01-register` | Sequence: register (Iteration 1) |
| `seq-02-login` | Sequence: log in (Iteration 1) |
| `seq-03-view-map` | Sequence: view trail map (Iteration 1) |
| `seq-04-search-trails` | Sequence: search trails by name or distance (Iteration 1) |
| `seq-05-view-trail-details` | Sequence: view trail details and conditions (Iteration 1) |
| `seq-06-submit-report` | Sequence: submit condition report, online only (Iteration 1) |
| `seq-07-import-trails` | Sequence: import trail data from Sport Ireland (Iteration 1, as built) |
