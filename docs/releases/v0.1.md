# TrailTrack v0.1

The Iteration 1 release: trails from the Sport Ireland National Trails
Register on a map, accounts, condition reports and trail search, for the 28
trails in County Laois.

## What's included

### Trails and the map
- An import of County Laois trails from the Sport Ireland National Trails
  Register, with each route's waymarking and official start point.
  Administrators only.
- Every trail on an OpenStreetMap base map, drawn in the colour of its
  waymark signs. National Waymarked Ways are yellow with a black edge.
- Routes that start from the same trailhead are grouped into a site, shown
  as a numbered pin when zoomed out. Shared paths show each route's colour
  side by side, and a tap on a shared path asks which route was meant.
- Tapping a route shows its name, difficulty and length, with a link to its
  details.
- A location button centres the map on the user's position.

### Trail details
- Each trail's facts, description and website, its current conditions, and
  the condition reports from the last 7 days.

### Accounts
- Registration and login with an email and password. Passwords are hashed
  with BCrypt, and the app keeps the login token in the phone's encrypted
  storage, so users stay logged in between launches.
- The first administrator is created from environment variables when the
  backend starts.

### Condition reports
- Logged-in users can report a trail's condition: one of 9 condition types,
  a severity and an optional note. Anyone can view reports without an
  account.
- A report sent again after a dropped connection is not stored twice.

### Search
- Search trails by name, or by distance from the user's position with
  "Near me" (5, 10 or 25 km, nearest first). Each result shows the trail's
  latest condition.

### Navigation
- A bottom navigation bar with Map, Search and Profile tabs. The Profile tab
  shows the logged-in account, with Log out, or Log in and Create account
  for guests.

## Testing

- Backend: 70 tests (unit, web layer, and integration tests against
  PostgreSQL with PostGIS).
- App: 100 unit and widget tests.

## Not in this release

Offline report queuing, moderation rules, community walks and condition
overlays on the map are planned for later iterations.
